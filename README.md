## Easy_TAREAN
Script for parsing TAREAN result using webscrapping (beautifulsoup). Also plots graphs of cluster annotation and allows for TAREAN annotation overwriting using additional libraries
(Useful for including annotations from libraries from EDTA, RepeatModeler2, etc). 


Installing python dependencies
```
pip install biopython pandas beautifulsoup4
```
Installing R dependencies 
```
Rscript -e 'install.packages(c("dplyr", "ggplot2", "viridis", "hash"), repos="http://cran.us.r-project.org")'
```
